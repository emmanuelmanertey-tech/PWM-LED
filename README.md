# ESP32 PWM Control & LED Fading

An embedded C++ project for the ESP32 microcontroller demonstrating Pulse Width Modulation (PWM) signal generation using the Arduino framework in PlatformIO.

---

## 📌 Overview

This project demonstrates how to control output signals using PWM to adjust hardware components like LEDs or motor drivers. It features two methods for controlling duty cycles:

**`analogWrite()` Method:** Quick and standard implementation.
